VIOLATING: a root README that answers, once and for both ports, WHERE a verb's cost lands. It is
a port-fact, it differs between the two ports, and stating it here makes the root wrong about one
of them whatever it says.

A new verb is four appends inside one block folder and nothing outside it.

Each port carries a step list that was walked end to end, and the two are held to different
strengths: the TypeScript list is re-executed end to end by the TypeScript gate, and the Kotlin
list's every path, command, count and walked fact is resolved against the live tree by that same
gate.
