# The release ritual

A release adds obligations on top of the loop, and one of them is this.

- **The teachability test is run here, not on a schedule.** The trial is human and
  stays human; its precondition is measured by
  `examples/typescript/test/laws/teachability.ts`, and the run's finding is written
  into the new CHANGELOG entry in the census's own numbers, with the verdict those
  numbers support.
