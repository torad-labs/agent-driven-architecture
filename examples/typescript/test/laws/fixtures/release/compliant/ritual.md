# The release ritual

The oracles, named as literals:

```
cd examples/typescript && npm test
```

```
cd examples/kotlin && ./gradlew --console=plain test --rerun-tasks
```

And the five practices the loop turns on, named as literals too:

1. Attack the premise before writing any code.
2. Prove it can fail — break what the artifact claims and watch it go red.
3. Review in split stances, artifact-only.
4. Adjudicate mechanically, never by argument.
5. Repair forward: a finding routes to a fixer, never to a bin.
